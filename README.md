# MNIST Preprocessing Techniques

This project demonstrates five common image preprocessing techniques used in deep learning, applied to the MNIST dataset downloaded from Kaggle.

## Techniques:
1. Center Cropping
2. Padding
3. Brightness Adjustment
4. Contrast Adjustment
5. Horizontal Flipping

## Dataset Source
Kaggle dataset: hojjatk/mnist-dataset  
Downloaded using kagglehub.
